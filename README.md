# Locadora

Sistema de locadora de filmes full stack, desenvolvido com TypeScript.

## Tecnologias
- Back-end: Node.js, Express, TypeScript
- Banco de dados: PostgreSQL
- Front-end: React, Next.js
- Versionamento: Git e GitHub

## Funcionalidades
- CRUD de clientes e filmes
- Registro de locações e devoluções com controle de estoque
- Listagem de locações com dados do cliente e do filme
- Filtro por status
